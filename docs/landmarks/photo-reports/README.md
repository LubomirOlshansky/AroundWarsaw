# Photo reports (from the Mac's refs/)

The reference photos themselves stay in `refs/<slug>/` on F's Mac (gitignored, Commons licences). These reports
are what a cloud thread builds from: positions in game coordinates read off the GUGiK orthophoto, sizes and
colours read off the photos, and the photo list with authors and licences. Written with the model-from-photos
skill; one file per `refs/` folder. A cloud thread that needs to see a photo asks the coordinator for a Mac check.
